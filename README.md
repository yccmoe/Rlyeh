# ⚓ Project R'lyeh (르리에)
> **Real-Time Beat-Synced Submarine Filter & Expression Master Pedal**  
> 기타 연주의 리듬을 실시간으로 추적하여 음표 블록 단위로 주파수 심해를 항해하고, 외부 이펙터까지 동시에 지휘하는 듀얼 디스플레이 잠수함 터미널 페달

---

## 📖 1. 프로젝트 개요 (Overview)

**R'lyeh(르리에)** 는 1970년대 냉전 시대 심해 잠수함의 소나 조종석 감성과 현대 일렉트로닉/밴드 사운드의 정밀한 리듬 필터링을 결합한 부티크 디지털-아날로그 하이브리드 기타 이펙터입니다.

* **핵심 컨셉:** 연주자의 피킹 리듬(BPM) 또는 외부 탭/생톤 신호를 실시간으로 동기화하고, 연주자가 소나 레이더 위에 직접 꽂은 **웨이포인트(`Ａ`, `Ｂ`, `Ｃ`, `Ｄ`...)** 항로를 따라 음표 블록 길이만큼 로우패스 필터(LPF)와 외부 익스프레션(`EXP OUT`)을 입체적으로 조종합니다.
* **듀얼 계측 디스플레이 & 상태 LED:**
  * **소나 레이더 HUD (2.4인치급 대형 OLED, `128×64`):** `32 | 64 | 32` 황금 분할 레이아웃. 정중앙 `64×64px` 원형 소나 레이더와 좌우 `32px` 날개 창에 현재 목표(`Ａ정박`)와 다음 목표(`Ｂ통과`), 좌표, 음표 길이 블록을 띄웁니다.
  * **심해 수심 계기판 (4자리 7-Segment LED):** 실제 DSP 내부 수심(`000` ~ `-256`)과 연동되어, 잠수 시 엘리베이터처럼 빠르게 요동치는 실시간 수심 수치를 표시합니다.
  * **3핀 바이컬러 상태 LED:** 현재 동기화 소스를 직관적으로 표시합니다 (**적색 점멸:** 자체 내장 오디오 감지 / **청색 점멸:** 외부 탭템포 허브 / **보라색 점멸:** `TAP IN` 외부 생톤 사이드체인).

## 🧠 2. 핵심 작동 논리 (Core Logic & Navigation)

### 2.1 3중 하이브리드 리듬 트래킹 (`TAP IN` 자동 판별 OS)
3.5mm `TAP IN` 포트에 들어오는 전기적 파형을 펌웨어가 실시간 분석하여 입력 소스를 자동으로 전환합니다.
1. **외부 탭템포 허브 모드 (청색 LED):** 외부 탭 모듈에서 들어오는 구형파(`0V ↔ 3.3V`) 펄스를 감지해 오차 없는 마스터 BPM으로 동기화합니다.
2. **외부 생톤 사이드체인 모드 (보라색 LED):** 드라이브 페달 앞단(예: `BOSS TU-3`의 `BYPASS` 출력)에서 분기된 클린 오디오 파형을 감지합니다. 왼손 뮤트 타격음(`800Hz~3kHz` 트랜지언트, 불응기 `150~200ms`)만으로도 정확한 BPM 락온(Lock-on)이 가능합니다.
3. **단독 내장 모드 (적색 LED):** `TAP IN` 미연결 시 메인 `IN` 오디오의 어택을 추적하여 자체 BPM 그리드를 생성합니다.
4. **비상 부상 로직 (Auto-Surface on Silence):** 잠수 중 일정 시간(1박자 이상) 입력 신호가 멈추면 먹먹한 톤 고립을 막기 위해 자동으로 모항(`000`)으로 복귀합니다.

### 2.2 음표 블록 조립 & 웨이포인트 항해 시스템
* **직관적인 음표 블록 길이 설정:** 소수점 마디 수 대신 뮤지션에게 익숙한 **고정폭 음표 아이콘(`𝅝` 온음표, `𝅗𝅥` 2분음표, `𝅘𝅥` 4분음표, `𝅘𝅥𝅮` 8분음표, `𝅘𝅥𝅯` 16분음표 등)**을 블록처럼 조립하여 항해 및 대기 시간을 설정합니다. (예: `[𝅝 𝅗𝅥]` = 1.5마디 동안 이동/대기)
* **정박(`STOP`) vs 통과(`PASS`) 모드:**
  * **정박 (`Ａ정박`):** 해당 좌표에 도달한 뒤, 설정된 음표 블록 길이만큼 심해에 머무르며 수심을 유지(Hold)합니다.
  * **통과 (`Ｂ통과`):** 해당 좌표에 도달하는 즉시 멈추지 않고 다음 웨이포인트로 부드럽게 변침합니다.
* **스마트 `EXP` 값 자동 승계:** 새 웨이포인트 편집 UI를 열면 직전 정류장의 `EXP(0~100%)` 값이 초기값으로 자동 승계(`newWaypoint.exp = prevWaypoint.exp`)되어 불필요한 반복 입력을 없앴습니다. (해당 항목은 `EXP OUT` 잭이 물리적으로 연결되었을 때만 활성화됩니다.)

### 2.3 내부 고해상도 수심 엔진 (`-256` ~ `+256`) & 조작 체계
* **고해상도 보간 연산:** UI 그리드는 조작 편의를 위해 `-4` ~ `+4` (0점 포함 9단계)로 표시되지만, 내부 오디오 DSP와 7세그먼트 수심계는 **`-256` ~ `+256` 고해상도 정수**로 보간 연산되어 계단 현상 없는 매끄러운 필터 스윕과 역동적인 수심 변화를 구현합니다.
* **원버튼 풋스위치 조작:**
  * **짧은 클릭 (토글):** 모항(`000`)에서 지정된 웨이포인트 항로를 따라 잠수 개시 / 항해 중 클릭 시 모항으로 부상 복귀.
  * **롱클릭 ($0.8\text{초}$ 이상):** 현재 수심이나 진행 상태와 무관하게 즉시 수면 위(`000`) 및 레이더 정중앙으로 비상 부상 리셋.

## 🖥️ 3. 소나 레이더 HUD 레이아웃 (`128 × 64 px`)

중앙 정사각형 원형 레이더(`64×64px`)를 상하 꽉 채우고 좌우 `32px` 날개에 3줄 여유 행간(약 `20px` 간격)을 배치한 전술 터미널 UI입니다.

```text
┌──────────┬────────────────────┬──────────┐
│ [Ａ정박  │      .  -+-  .     │ [Ｂ통과  │ ◀ 1줄: 전각 알파벳 + 정박/통과 (한/중/일/영 호환)
│  -3 -4   │    .   /  |  \   . │  +2 -1   │ ◀ 2줄: 반각 좌표 (수심 Depth / 공명 Reso)
│ [𝅝 𝅗𝅥]════│══▶  (   ⚓   )     │ [𝅘𝅥 𝅘𝅥]    │ ◀ 3줄: 음표 블록 (길어지면 레이더 위로 HUD 오버랩)
└──────────┴────────────────────┴──────────┘
  좌 (32px)      중앙 (64px)      우 (32px)

```

* **타이포그래피 규격:**
* **전각(`12~14px` 폭):** 웨이포인트 식별자(`ＡＢＣＤ`) 및 상태(`정박`/`통과`, `停泊`/`通過`, 반각 `STOP`/`PASS` 4글자)를 큼직하게 배치하여 다국어 레이아웃 규격을 통일합니다.
* **반각(`6px` 폭):** 좌표(`-3 -4`, 공백 포함 5칸 = `30px`)를 좌우 날개 안에 정밀 정렬합니다.
* **음표 아이콘:** 고정폭 도트 비트맵으로 제작하여 나열 시 격자가 어긋나지 않으며, 블록이 길어질 경우 중앙 레이더 위로 겹쳐 투영되는 잠망경 HUD 연출을 적용합니다.

## 🔌 6. 배선, 보호 회로 및 실전 세팅 가이드

*Teensy 4.0과 Audio Shield 결합 후 전용 핀(`7, 8, 18, 19, 20, 21, 23`번)을 회피하여 할당합니다.*

### 6.1 전원부 및 7-Segment 노이즈 필터링

1. **극성 변환 및 강압:** 2.1mm DC 잭의 바깥쪽 슬리브(`+9V`)를 MP1584EN의 `IN+`에, 가운데 심(`GND`)을 `IN-`에 연결하고, `OUT+`(`5V`)를 Teensy `VIN`에 연결합니다.
2. **디커플링 커패시터 배치:** MP1584EN 출력단 및 **7-Segment 전원 핀(`VCC`-`GND`) 바로 코앞**에 **`100uF 25V` 전해 콘덴서**(흰색 띠가 `GND` 방향)와 **`100nF (0.1uF, 104)` 세라믹 콘덴서**를 나란히 병렬 연결하여 수심 숫자 고속 갱신(`초당 약 85회 이상`) 시 발생하는 전원 리플이 오디오로 유입되는 것을 차단합니다.

### 6.2 `TAP / SENSE IN` 겸용 보호 및 바이어스 회로 (3.5mm)

5V 디지털 탭 펄스와 ±1V 기타 생톤 오디오를 모두 안전하게 수신하기 위해 Teensy 아날로그 핀(`A0`) 앞단에 아래 회로를 구성합니다.

* **AC 커플링 및 바이어스:** `1uF` 커플링 커패시터 통과 후 `10kΩ` 저항 두 개로 `3.3V`를 분압하여 `1.65V` 중심점을 잡습니다.
* **과전압 클램핑:** `BAT54S` 쇼트키 다이오드를 `3.3V`와 `GND` 사이에 연결하여 5V 탭 신호 유입 시 핀 전압을 안전하게 제한합니다.

### 6.3 `EXP OUT` 잭 삽입 감지 및 디지털 포텐셔미터 (`MCP41010`)

* **잭 삽입 자동 감지:** 6.35mm TRS **스위치 내장형 잭**의 단락 핀을 Teensy 디지털 입력(`INPUT_PULLUP`)에 연결합니다. 케이블 삽입으로 단락이 해제될 때만 펌웨어가 `EXP OUT` 연결을 인식하여 노트 편집 UI의 `EXP` 항목을 해금합니다.
* **외부 페달 제어:** `MCP41010`의 `PA0`, `PW0`, `PB0` 핀을 각각 TRS 잭의 Ring, Tip, Sleeve에 연결하여 상용 이펙터에 수동 익스프레션 페달과 동일한 물리 저항값을 전달합니다.

### 6.4 드라이브 뒷단 사용 시 무적 세팅 (튜너 듀얼 아웃 분기)

드라이브 페달 뒷단에 르리에를 배치할 경우, 보유 중인 튜너(`BOSS TU-3`)의 듀얼 버퍼 출력을 활용하면 톤 손실 없이 100% 칼박 감지가 가능합니다.

* **메인 오디오 경로:** 기타 $\rightarrow$ `TU-3 OUTPUT` $\rightarrow$ 드라이브 페달 $\rightarrow$ **르리에 `IN` $\rightarrow$ `OUT**`
* **박자 감지 경로:** `TU-3 BYPASS` (상시 클린 출력) $\rightarrow$ 6.35-to-3.5mm 케이블 $\rightarrow$ **르리에 `TAP IN**` (보라색 LED 자동 점등)

## 🚀 7. 빌드 및 펌웨어 로드 순서 (Build Steps)

1. **전원부 조립 및 검증:** MP1584EN 출력단에 `100uF 25V` 전해 콘덴서와 `100nF` 세라믹 콘덴서를 병렬 납땜한 뒤, 멀티미터로 `5.0V` 출력을 확인하고 Teensy `VIN`에 연결합니다.
2. **오디오 쉴드 및 모듈 적층 배선:** Teensy 4.0과 Audio Shield를 핀 헤더로 적층한 뒤, 7핀 SPI OLED, TM1637 7-Segment, `MCP41010`, 3핀 바이컬러 LED, 4포트 잭 및 보호 회로를 배선합니다.
3. **케이스 타공 및 절연:** 상판 도면에 맞춰 4포트 I/O와 디스플레이 창을 가공하고, 보호창(무반사 아크릴 또는 미네랄 글래스) 장착 후 두 디스플레이 모듈 뒷면을 캡톤 테이프로 철저히 절연합니다.
4. **펌웨어 업로드:** Arduino IDE에서 `Teensyduino` 보드 패키지와 `U8g2`, `TM1637Display`, `SPI` 라이브러리를 설치한 뒤, 고정폭 음표 비트맵 폰트와 항해 OS 소스코드를 컴파일하여 업로드합니다.

```

```
